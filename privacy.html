Политика конфиденциальности

1. Общие положения

Настоящая политика конфиденциальности определяет порядок обработки и защиты персональных данных пользователей сайта PrismaClub.

2. Какие данные собираются

  • Имя пользователя
  • Номер телефона
  • Email адрес
  • Информация, указанная в формах сайта

3. Цели обработки данных

Персональные данные используются для:

  • Связи с пользователем
  • Консультации по услугам
  • Записи на занятия
  • Обработки заявок
  • Информирования об услугах

4. Защита данных

Администрация сайта принимает необходимые меры для защиты персональных данных пользователей.

5. Передача данных

Персональные данные не передаются третьим лицам, кроме случаев, предусмотренных законодательством РФ.

Для обработки заявок могут использоваться сторонние сервисы, включая Formspree.

6. Согласие пользователя

Отправляя формы на сайте, пользователь подтверждает согласие на обработку персональных данных.
